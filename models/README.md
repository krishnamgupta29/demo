# Models Directory

> **WEIGHT STORAGE DIRECTIVE:**
> - Binary model weights (`*.pt`, `*.pth`, `*.onnx`, `*.bin`, `*.engine`) are excluded from git.
> - Verified checkpoints and ONNX exports reside here during local runtime.
> - For storage constraints, multi-gigabyte foundation models are run via local Ollama (`C:\Users\<user>\.ollama`) rather than duplicated on `D:`.
