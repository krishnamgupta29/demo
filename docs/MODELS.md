## 2. Release Archive Setup Instructions (For Fresh Clones)

Binary model weights (`*.onnx`) are deliberately excluded from git version control to keep repository clones fast and lightweight (< 5 MB).

On a fresh clone, install the pre-packaged release zip:

### Step 1: Download Release Archive
Download `dentrace_models_default_v1.0.zip` (61.74 MB) from GitHub Releases or copy from `C:\release\`.

### Step 2: Unzip Into Project Root
In PowerShell at the project root:
```powershell
Expand-Archive -Path "C:\release\dentrace_models_default_v1.0.zip" -DestinationPath "." -Force
```
*Result:* Unpacks the four required default models into `models/checkpoints/` alongside `SHA256SUMS.txt`.

### Step 3: Verify Integrity
Run the automated verification script:
```powershell
.venv\Scripts\python.exe scripts/verify_fresh_clone_with_zip.py
```
*Expected output:*
```
All release models verified successfully with 100% SHA-256 match!
```

## 3. Local Ollama LLM Setup

DENTRACE operates strictly offline with zero external cloud egress. Pre-authorization narratives are generated by a local Ollama daemon:

1. Install Ollama: [https://ollama.com](https://ollama.com)
2. Pull the target clinical SLM:
   ```bash
   ollama pull qwen2.5:3b
   ```
3. Start the Ollama server:
   ```bash
   ollama serve
   ```
   *Note: DENTRACE automatically prompts Ollama with `num_gpu: 0` during CPU benchmarks to prevent VRAM exhaustion on clinic laptops with entry-level GPUs.*
